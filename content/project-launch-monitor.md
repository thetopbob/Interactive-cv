A homebrew launch monitor, built to track a 20-handicap golf game one range session at a time.

- Camera-based capture using the Arducam B0332 OV9281
- Python, OpenCV, and Pygame for the capture and analysis stack
- Feeds a longitudinal dataset used to spot swing patterns over time

Fair warning: this NPC will talk your ear off about face-angle oscillation.
